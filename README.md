# QuickNotes App

QuickNotes is a lightweight, responsive web application designed to help users quickly capture, categorize, and organize their daily thoughts, work items, and study notes. Built with plain HTML5, CSS3, and modern JavaScript, it offers a seamless experience with zero external dependencies.

## Features

- **Categorized Notes:** Assign categories (Personal, Work, Study) with custom visual color indicators.
- **Form Validation:** Prevents empty submissions and limits note length to 200 characters.
- **Real-Time Search:** Instantly filter notes by keyword as you type.
- **Data Persistence:** Automatically saves all notes to `localStorage` so data survives page refreshes.
- **Responsive Layout:** Adaptive design with a desktop-friendly layout that smoothly stacks on screens under 600px.
- **Bulk Clear (Bonus):** Quick "Clear All" option with confirmation modal protection.
